**Инструмент для научного исследования голоса и биометрической идентификации.**

Проект представляет собой гибридную систему распознавания речи и идентификации говорящего, объединяющую современные нейросетевые технологии (Deep Learning) и классические методы цифровой обработки сигналов (DSP).

---

##  О проекте

**TVE** - это десктопное приложение (WPF), разработанное в рамках научно-исследовательской работы. Оно решает три задачи:
1. **Распознавание речи** (Speech-to-Text).
2. **Идентификация говорящего** (Speaker Verification).
3. **Акустический анализ** - извлечение математических характеристик голоса (F0, гармоники, форманты) для научных исследований.

---

##  Основные возможности

- 🎤 **Запись и VAD**: Захват аудио с микрофона (16 кГц, моно) с автоматическим отсечением тишины по RMS-порогу.
- 🗣 **Распознавание речи**: Локальная нейросеть **Whisper.net** (модель `ggml-base`) от OpenAI, работающая без интернета.
- 🧬 **Идентификация голоса**: Извлечение 512-мерных эмбеддингов через **ERes2Net-Base** (sherpa-onnx) и сравнение по косинусному сходству.
- 🧠 **Умное слияние профилей**: Обновление эталонов методом **SLERP** (сферическая интерполяция) с адаптивным весом.
- 🎛 **DSP-анализ**: Извлечение F0 тремя методами (Кепстр, HPS, Автокорреляция), поиск гармоник (k1-k8) и формант (F1-F4 через LPC 22-го порядка).
- 📊 **Визуализация**:
  - **Карта голосов**: PCA-проекция 512D в 2D, кластеризация K-Means, выпуклые оболочки (Convex Hull).
  - **Матрица сходства** и **Спектрограммы**.
  - **Слияние эмбеддингов** (визуализация SLERP).
- 📁 **Обработка файлов**: Drag-and-Drop аудиофайлов (MP3, WAV, FLAC, OGG, M4A) с кластеризацией голосов.
- 💾 **Экспорт**: Выгрузка эмбеддингов (512 значений) и акустических профилей в CSV/Excel.

##  Архитектура проекта

Проект разделен на три части:

* **`TVE.Core`** - библиотека классов (`net10.0`), содержащая всю логику:
  * `Audio/` - захват микрофона, VAD, декодирование.
  * `Analysis/` - DSP-анализ (гармоники, форманты), PCA, K-Means, SLERP.
  * `Recognition/` - обертка над Whisper.
  * `Speaker/` - извлечение эмбеддингов, кластеризация.
  * `Storage/` - работа с LiteDB.
* **`TVE.Ui`** - WPF-приложение (`net10.0-windows`), отвечающее за интерфейс и визуализацию.
* **`TVE.HarmonicTest`** - консольный проект для модульного тестирования математических алгоритмов.

##  Установка и запуск

### 1. Клонирование репозитория

Скопируйте и выполните в терминале команду:

git clone https://github.com/rostef-commits/TVE.git
cd TVE

### 2. Подготовка моделей (ВАЖНО)

Из-за ограничений GitHub, тяжелые модели не включены в репозиторий. Скачайте их и положите в папку `TVE.Ui/Models/`:
1. **`ggml-base.bin`** (модель Whisper, ~74 МБ).
2. **`3dspeaker_speech_eres2net_base_200k_sv_zh-cn_16k-common.onnx`** (модель ERes2Net, ~25 МБ).

### 3. Сборка и запуск

1. Откройте файл **`TVE.sln`** в Visual Studio 2022.
2. Восстановите **NuGet-пакеты** (если они не подтянулись автоматически).
3. Соберите решение через меню **Build -> Rebuild Solution**.
4. Запустите проект **`TVE.Ui`**, нажав **F5**.

##  Решение проблем (Troubleshooting)

**Проблема с AMD Ryzen и драйвером Vulkan:**
На некоторых ноутбуках (например, AMD Ryzen 5 7540U + Windows 11) WPF-приложение может падать с ошибкой `0xc0000409` из-за бага драйвера `amdvlk64.dll`.

**Решение:** В корне проекта лежит файл **`run_tve.bat`**. Запускайте программу через него. Он безопасно отключает Vulkan для процесса, не ломая систему.

##  Внутреннее устройство (Как это работает)

### Захват аудио и VAD
Класс `MicrophoneCapture` использует `WaveInEvent` (NAudio) для получения звука (16 кГц, моно). Алгоритм VAD в `OnDataAvailable` вычисляет RMS для каждого буфера (50 мс). Если RMS > 0.01 - идет речь. Если тишина длится более 800 мс, сегмент отправляется на обработку. Watchdog-таймер проверяет наличие микрофона каждые 2 секунды.

### Проверка качества
Перед отправкой в нейросеть звук проверяется: длина (мин. 400 мс) и громкость (RMS > 0.008). Проверка на два голоса: если сегмент > 3.5 сек, он делится пополам, и если косинусное сходство между эмбеддингами половин < 0.55 - звук отбрасывается.

### Эмбеддинги и База данных
`VoiceEmbedder` (sherpa-onnx) извлекает вектор из 512 чисел. Метод `FindClosestSpeaker()` в `VoiceDatabase` (LiteDB) перебирает всех спикеров, считает косинусное сходство `sim = (a * b) / (||a|| * ||b||)` и выполняет двойную проверку: лучший результат должен быть > 0.55 И отрываться от второго места на 0.05 (margin). Если margin маленький - создается новый пользователь.

### DSP-анализ
`HarmonicAnalyzer` ищет F0 тремя методами (Кепстр, HPS, Автокорреляция) с голосованием для отсечения октавных ошибок. Форманты (F1-F4) ищутся через LPC 22-го порядка. Спектрограмма строится через FFT с окном Ханна.

### Математика визуализации
- **PCA**: сжимает 512D векторы в 2D для отрисовки на экране.
- **K-Means**: разбивает точки на группы похожих голосов.
- **SLERP**: сферическая интерполяция для умного обновления эмбеддинга (движение по дуге, а не сквозь сферу).

##  Пользовательский интерфейс

* **Главное окно (`HomeView`)**: Круглая кнопка записи, панели с распознанным текстом и Drag-and-Drop аудиофайлов.
* **Голоса в базе (`VoicesView`)**: Таблица пользователей (inline-редактирование имен, описания, история реплик).
* **Анализ (`AnalysisWindow`)**:
  * *Матрица сходства*: таблица косинусных сходств (от 0 до 1).
  * *Карта голосов*: визуализация 512D векторов на 2D-плоскости с кластерами.
  * *Гармоники*: график спектра с пиками (гармониками) и формантами.
  * *Слияние*: визуализация SLERP.
* **Настройки (`SettingsView`)**: Выбор микрофона, темы, пути к БД, экспорт/импорт.
