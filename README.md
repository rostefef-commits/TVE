---

## 📖 О проекте

**TVE** — это десктопное приложение (WPF), разработанное в рамках научно-исследовательской работы. Оно решает задачи распознавания речи, идентификации говорящего и математического анализа акустических характеристик голоса (F0, гармоники, форманты).

В отличие от классических реализаций (чистый DSP на Go или только нейросети на Python), в данном проекте используется **гибридный подход**.

---

## ✨ Основные возможности

- 🎤 **Запись и VAD**: Захват аудио с микрофона с автоматическим отсечением тишины (RMS-порог).
- 🗣 **Распознавание речи**: Локальная нейросеть **Whisper.net** (модель `ggml-base`).
- 🧬 **Идентификация голоса**: Извлечение 512-мерных эмбеддингов через **ERes2Net-Base** (sherpa-onnx).
- 📈 **Продвинутая математика**:
  - Обновление профиля методом **SLERP** (сферическая интерполяция).
  - Margin-проверка для защиты от ложных срабатываний.
- 🎛 **DSP-анализ**: Извлечение F0 тремя независимыми методами (Кепстр, HPS, Автокорреляция), поиск гармоник (k1-k8) и формант (F1-F4 через LPC).
- 📊 **Визуализация**:
  - Карта голосов (PCA + K-Means + Convex Hull).
  - Матрица косинусных сходств.
  - Спектрограммы и графики слияния эмбеддингов.
- 📁 **Импорт/Экспорт**: Поддержка Drag-and-Drop аудиофайлов и экспорт данных в CSV.

## 🛠 Технологический стек

### Core & UI
- **Язык**: C# 13
- **Платформа**: .NET 10, WPF (Windows Presentation Foundation)
- **Архитектура**: Разделение на библиотеку классов (`TVE.Core`) и интерфейс (`TVE.Ui`)

### Нейросети и Математика
- **Whisper.net** — распознавание речи (OpenAI, 2022)
- **sherpa-onnx** — извлечение эмбеддингов (Alibaba 3D-Speaker, 2022)
- **NAudio** — захват и обработка аудиопотока
- **LiteDB** — встроенная NoSQL база данных
- **OxyPlot** — построение графиков
